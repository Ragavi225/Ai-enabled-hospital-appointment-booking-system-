# AI-Enabled Hospital Appointment Booking System

• Project Overview
  This project is a web-based hospital appointment booking system that allows patients to schedule appointments with doctors online.

• Features
  - Patient registration
  - Appointment booking
  - Doctor selection
  - Date scheduling
  - User-friendly interface

• Technologies Used
  - HTML
  - CSS
  - JavaScript

• Future AI Enhancements
   - AI-based doctor recommendation
   - Smart appointment scheduling
   - Health chatbot
   - Automated reminders
