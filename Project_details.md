AI-Enabled Hospital Appointment Booking System

Project Title

AI-Enabled Hospital Appointment Booking System

Problem Statement

Traditional hospital appointment booking methods often lead to long waiting times, scheduling conflicts, and inefficient management of patient records. Patients face difficulties in finding suitable doctors and booking appointments conveniently. This project aims to provide an AI-powered solution that simplifies appointment scheduling, improves hospital efficiency, and enhances patient experience.

Project Objectives

- To provide online appointment booking for patients.
- To reduce waiting time through efficient scheduling.
- To recommend suitable doctors based on patient requirements using AI.
- To automate appointment management and notifications.
- To improve accessibility and user experience in healthcare services.
- To maintain patient and appointment records securely.

Modules List

2. Patient Dashboard
3. Doctor Management
4. AI Doctor Recommendation

6. Appointment Scheduling
7. Notification & Reminder System
8. Admin Dashboard

10. Reports & Analytics

Database Tables List

Table Name| Description

Doctors| Stores doctor information
Appointments| Stores appointment details
Departments| Stores hospital departments
Doctor_Schedules| Stores doctor availability
AI_Recommendations| Stores AI-generated doctor suggestions
Notifications| Stores appointment reminders
Medical_Records| Stores patient medical history
Feedback| Stores patient feedback and ratings
Admin| Stores administrator details

Expected Outcome

The system enables patients to book appointments online, receive AI-based doctor recommendations, get appointment reminders, and reduce hospital waiting times while improving healthcare service management.

Technologies Used

- Backend: Python (Flask) / Node.js
- Database: MySQL
- AI Module: Machine Learning Recommendation System
